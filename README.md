Questões usadas:

Array:

1.
Soma de todos os elementos
Dado um array de inteiros, retorne a soma de todos os seus elementos. Exemplo: [1,2,3,4] → 10.

2.
Encontrar o maior elemento
Percorra um array e retorne o maior valor encontrado sem usar funções nativas de máximo. Exemplo: [3,7,2,9,1] → 9.

3.
Inverter um array
Dada uma lista de elementos, retorne-a na ordem inversa sem usar funções prontas de reversão. Exemplo: [1,2,3] → [3,2,1].

4.
Remover duplicatas
Dado um array com valores repetidos, retorne um novo array com apenas elementos únicos, mantendo a ordem de primeira aparição. Exemplo: [1,2,2,3,1,4] → [1,2,3,4].

5.
Rotação de array (k posições)
Dado um array e um inteiro k, rotacione todos os elementos k posições à direita de forma circular. Exemplo: [1,2,3,4,5], k=2 → [4,5,1,2,3].

Lista encadeada:

6.
Inserir no início da lista
Implemente uma função que insira um novo nó no início de uma lista encadeada simples, atualizando corretamente o ponteiro de cabeça.

7.
Contar nós da lista
Percorra uma lista encadeada do início ao fim e retorne o número total de nós presentes. Exemplo: 1→2→3→null → 3.

8.
Inverter lista encadeada
Dada uma lista encadeada simples, inverta todos os ponteiros de modo que o último nó se torne o novo cabeça. Faça isso iterativamente. Exemplo: 1→2→3 → 3→2→1.
Lista encadeada

9.
Detectar ciclo na lista
Implemente o algoritmo de Floyd (dois ponteiros: lento e rápido) para detectar se uma lista encadeada contém um ciclo. Retorne verdadeiro ou falso.

Pilha:

10.
Implementar pilha com array
Implemente uma pilha básica usando um array, com as operações push (empilhar), pop (desempilhar) e peek (ver o topo) sem usar estruturas prontas.

11.
Validar parênteses balanceados
Dada uma string contendo '(', ')', '{', '}', '[', ']', use uma pilha para verificar se todos os pares estão corretamente abertos e fechados. Exemplo: '({[]})' → válido; '([)]' → inválido.

12.
Converter decimal para binário
Usando uma pilha, converta um número inteiro positivo da base decimal para binário. Empilhe os restos das divisões por 2 e os desempilhe para formar o resultado. Exemplo: 13 → '1101'.
